Angular 21 UI/UX Mimarisi, Reusable Bileşenler & A11y Standartları

Component-Driven / Atomic Design hiyerarşisi, reaktif Dark/Light tema motoru, kurumsal Toast ve Modal altyapısı, Zoneless OnPush veri tabloları ve WCAG 2.1 AA erişilebilirlik standartları.

1

Atomic Design Bileşen Hiyerarşisi

Bileşenler yeniden kullanılabilirlik ve bağımsızlık seviyelerine göre src/app/shared/components/ altında ayrıştırılır.

  • Atoms: Button, Badge, Spinner, Checkbox, Avatar (İş mantığı içermeyen en küçük saf birimler).
  • Molecules: SearchBar, FormField (Label + Input + Error), Breadcrumb.
  • Organisms: DataTable (filtre, sıralama, sayfalama birleşik), Shell Navbar, Sidebar.
  • Shell / Layout: Tüm ekranı sarmalayan kurumsal uygulama kabuğu.
2

Sinyal Tabanlı Reaktif Tema Motoru (ThemeService)

Kullanıcı tercihi LocalStorage ve sistem tercihi (`prefers-color-scheme`) ile senkronize edilir.

src/app/core/services/theme.service.ts
TypeScript
import { Injectable, signal, effect } from '@angular/core';

@Injectable({ providedIn: 'root' })
export class ThemeService {
  readonly currentTheme = signal<'dark' | 'light'>('dark');

  constructor() {
    effect(() => {
      document.documentElement.setAttribute('data-theme', this.currentTheme());
      localStorage.setItem('theme', this.currentTheme());
    });
  }

  toggle(): void {
    this.currentTheme.update(t => t === 'dark' ? 'light' : 'dark');
  }
}

Kurumsal UI Kiti (Toast & Modal)

Global bildirimler sinyal tabanlı Toast servisi ile yönetilir. Diyalog pencerelerinde odak yakalama (focus trap) ve klavye gezintisi zorunludur.

WCAG 2.1 AA Erişilebilirlik Standartları

Tüm butonlarda `aria-label`, diyaloglarda `role="dialog"`, formlarda `aria-describedby` ile hata ilişkisi ve klavye odağı (`focus-visible`) kurumsal şarttır.
