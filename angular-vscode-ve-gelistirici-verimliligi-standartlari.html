Angular 21 VS Code Kurulumu & Geliştirici Verimliliği Standartları

Ekip genelinde standardize edilen VS Code çalışma alanı, zorunlu eklenti listesi, otomatik format-on-save ve ESLint düzeltmeleri, Chrome yerel TypeScript breakpoint debugging ve kurumsal kod parçacıkları (snippets).

1

Zorunlu Eklentiler (.vscode/extensions.json)

Projeyi yeni klonlayan her geliştiriciye editör tarafından otomatik önerilir:

.vscode/extensions.json
JSON
{
  "recommendations": [
    "angular.ng-template",
    "bradlc.vscode-tailwindcss",
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",
    "eamodio.gitlens",
    "editorconfig.editorconfig",
    "vitest.explorer"
  ]
}
2

Çalışma Alanı Ayarları (.vscode/settings.json)

Kaydetme anında Prettier formatlaması ve otomatik ESLint kural onarımı:

.vscode/settings.json
JSON
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "editor.tabSize": 2,
  "editor.insertSpaces": true,
  "typescript.tsdk": "node_modules/typescript/lib"
}
3

Chrome Yerel Hata Ayıklama (.vscode/launch.json)

F5 tuşuna basarak doğrudan VS Code içerisinden breakpoint ile hata ayıklama:

.vscode/launch.json
JSON
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Angular 21: Chrome Debugger",
      "type": "chrome",
      "request": "launch",
      "url": "http://localhost:4200",
      "webRoot": "${workspaceFolder}",
      "sourceMaps": true
    }
  ]
}
4

Kurumsal Kod Parçacıkları (Snippets)

Hızlı ve standartlara uygun kod üretimi için tanımlanan şablonlar:

  • ng-signal-comp: Zoneless, OnPush, Standalone bileşen iskeleti.
  • ng-signal-store: State, computed selector ve mutation içeren kurumsal Signal Store şablonu.
  • ng-func-guard: CanActivateFn fonksiyonel guard şablonu.
  • ng-func-interceptor: HttpInterceptorFn fonksiyonel interceptor şablonu.
