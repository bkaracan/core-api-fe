Angular 21 Proje Kurulumu, Konfigürasyon ve Bağımlılık Standartları

Spring Boot REST API ekosistemleri ile entegre çalışacak modern Angular 21 projeleri için Node.js 24 LTS, CLI üretim parametreleri, katı derleme bütçeleri, ESLint Flat Config, Prettier ve Husky kalite kapısı rehberi.

1

Standardize CLI İlklendirme Komutu

Geliştirici inisiyatifine bırakılan etkileşimli sorular yerine aşağıdaki tek ve bağlayıcı CLI bayrakları ile proje iskeleti üretilmelidir.

Terminal • Proje İlklendirme
Bash
ng new core-frontend-portal \
  --routing=true \
  --style=scss \
  --ssr=false \
  --standalone=true \
  --inline-style=false \
  --skip-tests=false \
  --package-manager=npm
PowerShell • Proje İlklendirme
PowerShell
ng new core-frontend-portal --routing --style=scss --ssr=false --standalone --inline-style=false --skip-tests=false --package-manager=npm
Bayrak (Flag) Değer Kurumsal Zorunluluk Nedeni
--routing true Modern fonksiyonel rota dosyasını (app.routes.ts) otomatik ilklendirir.
--style scss Modern SCSS değişkenleri, mixin ve nesting desteği sunar.
--ssr false Kurumsal intranet ve yetkilendirmeli (authenticated) portallar için saf Client-Side SPA mimarisi.
--standalone true NgModule kullanımını tamamen engeller; %100 Standalone bileşenler üretir.
--inline-style false CSS/SCSS kodlarının ayrı dosyalarda tutulmasını zorunlu kılar.
--skip-tests false Birim testlerin (spec.ts) atlanmasını önler.

angular.json Kurumsal Konfigürasyonu & Bütçeler

Angular 21'de yeni nesil @angular/build:application esbuild derleyicisi kullanılır. İlk yükleme boyutunun kontrol altında tutulması için katı bütçe (budget) limitleri uygulanır.

angular.json (Budgets Snippet)
JSON
{
  "configurations": {
    "production": {
      "budgets": [
        {
          "type": "initial",
          "maximumWarning": "500kB",
          "maximumError": "1MB"
        },
        {
          "type": "anyComponentStyle",
          "maximumWarning": "4kB",
          "maximumError": "8kB"
        }
      ],
      "outputHashing": "all",
      "optimization": true,
      "sourceMap": false,
      "extractLicenses": true
    }
  }
}
Bütçe Aşımı Neden Kritik?

Initial bundle boyutu 1MB'ı aştığında derleme hata vererek CI/CD sürecini durdurur. Bu durum geliştiricileri rota seviyesinde lazy loading ve @defer kullanmaya zorlar.

tsconfig.json & Kurumsal Path Aliases

Karmaşık ve kırılgan bağıl dosya yolları (../../../../core/auth) yasaktır. Temiz katman sınırları için path mapping tanımlanır:

tsconfig.json
JSON
{
  "compilerOptions": {
    "baseUrl": "./",
    "strict": true,
    "noImplicitOverride": true,
    "noPropertyAccessFromIndexSignature": true,
    "noImplicitReturns": true,
    "paths": {
      "@core/*": ["src/app/core/*"],
      "@features/*": ["src/app/features/*"],
      "@shared/*": ["src/app/shared/*"],
      "@layout/*": ["src/app/layout/*"],
      "@env/*": ["src/environments/*"]
    }
  }
}

ESLint Flat Config & Prettier Standartları

ESLint v9+ Flat Config formatı ve Prettier formatlayıcısı ile takım genelinde sıfır stil tartışması hedeflenir.

eslint.config.js
JavaScript
import tseslint from 'typescript-eslint';
import angular from 'angular-eslint';

export default tseslint.config(
  {
    files: ['**/*.ts'],
    extends: [
      ...tseslint.configs.recommended,
      ...tseslint.configs.stylistic,
      ...angular.configs.tsRecommended
    ],
    processor: angular.processInlineTemplates,
    rules: {
      '@angular-eslint/directive-selector': ['error', { type: 'attribute', prefix: 'app', style: 'camelCase' }],
      '@angular-eslint/component-selector': ['error', { type: 'element', prefix: 'app', style: 'kebab-case' }],
      '@angular-eslint/prefer-on-push-component-change-detection': 'error',
      '@typescript-eslint/explicit-function-return-type': 'error',
      '@typescript-eslint/no-explicit-any': 'error'
    }
  },
  {
    files: ['**/*.html'],
    extends: [...angular.configs.templateRecommended, ...angular.configs.templateAccessibility],
    rules: {
      '@angular-eslint/template/prefer-control-flow': 'error'
    }
  }
);

Tailwind CSS v4 & SCSS Mimarisi

Tailwind CSS v4, doğrudan CSS tabanlı `@theme` blokları ve PostCSS eklentisiyle Angular 21'e entegre edilir.

src/styles.scss
SCSS
@import "tailwindcss";

@theme {
  --color-brand-primary: #e11d48;
  --color-brand-dark: #0b0f19;
  --color-brand-panel: #0f172a;
  --font-mono: "JetBrains Mono", monospace;
}

:root {
  color-scheme: dark;
}

[data-theme="light"] {
  color-scheme: light;
}

Husky & lint-staged Kalite Kapısı

Geliştirici `git commit` attığı anda yalnızca değiştirilen dosyalar otomatik olarak denetlenir:

package.json (lint-staged)
JSON
{
  "lint-staged": {
    "*.{ts,html}": [
      "eslint --fix",
      "prettier --write"
    ],
    "*.{scss,json,md}": [
      "prettier --write"
    ]
  }
}
Kopyalandı!
