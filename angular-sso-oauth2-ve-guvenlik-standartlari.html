OAuth 2.1 & Web Crypto PKCE Mimarisi

SPA uygulamalarında client_secret bulunamaz. Yetkilendirme kodu akışı SHA-256 PKCE ile korunur.

src/app/core/auth/pkce.utils.ts
TypeScript
export async function generateCodeVerifier(): Promise<string> {
  const array = new Uint8Array(64);
  window.crypto.getRandomValues(array);
  return base64UrlEncode(array);
}

export async function generateCodeChallenge(verifier: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(verifier);
  const digest = await window.crypto.subtle.digest('SHA-256', data);
  return base64UrlEncode(new Uint8Array(digest));
}

function base64UrlEncode(buffer: Uint8Array): string {
  let str = '';
  for (let i = 0; i < buffer.length; i++) str += String.fromCharCode(buffer[i]);
  return btoa(str).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

In-Memory Token Saklama Disiplini

LocalStorage veya SessionStorage XSS açıklarına karşı savunmasızdır. Access Token yalnızca Angular AuthService içinde reaktif bir sinyalde tutulmalıdır.

Zero-Trust Token Saklama

Access token asla localStorage.setItem('token', ...) şeklinde diske yazılmaz. Refresh token ise HttpOnly çerez ile arka uç tarafından korunmalıdır.

Rol Tabanlı Yetkilendirme (RBAC) Direktifi

Yetkisiz kullanıcılar için DOM elemanlarının render edilmesini engelleyen yapısal direktif standardı:

src/app/shared/directives/has-role.directive.ts
TypeScript
import { Directive, TemplateRef, ViewContainerRef, input, effect, inject } from '@angular/core';
import { AuthService } from '@core/auth/auth.service';

@Directive({
  selector: '[appHasRole]',
  standalone: true
})
export class HasRoleDirective {
  readonly appHasRole = input.required<string[]>();

  private readonly templateRef = inject(TemplateRef);
  private readonly viewContainer = inject(ViewContainerRef);
  private readonly auth = inject(AuthService);

  constructor() {
    effect(() => {
      const required = this.appHasRole();
      const userRoles = this.auth.userRoles();
      const hasPermission = required.some(r => userRoles.includes(r));

      this.viewContainer.clear();
      if (hasPermission) {
        this.viewContainer.createEmbeddedView(this.templateRef);
      }
    });
  }
}
