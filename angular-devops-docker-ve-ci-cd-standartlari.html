Angular 21 DevOps, Dockerization, Nginx & CI/CD Standartları

Node 24 Alpine ve Nginx 1.27 Alpine tabanlı multi-stage Docker mimarisi, SPA rotalama fallback'i, katı statik önbellekleme kuralları, HSTS/CSP güvenlik başlıkları ve GitHub Actions CI/CD yaşam döngüsü.

1

Multi-Stage Dockerfile Mimarisi

Üretim paketleri Node.js 24 Alpine üzerinde inşa edilir; son imaj yalnızca Nginx Alpine ve derlenmiş statik dosyaları içererek <25MB boyutuna indirgenir.

Dockerfile
Dockerfile
# STAGE 1: Build
FROM node:24-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build -- --configuration=production

# STAGE 2: Runtime
FROM nginx:1.27-alpine AS runner
WORKDIR /usr/share/nginx/html
RUN rm -rf ./*
COPY --from=builder /app/dist/core-frontend-portal/browser .
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
2

Kurumsal Nginx Konfigürasyonu (nginx.conf)

SPA rotalarının 404 vermemesi için `try_files $uri $uri/ /index.html;` ve statik dosyalar için 1 yıllık immutable önbellekleme uygulanır.

nginx.conf
Nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    gzip on;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml;

    location ~* \.(?:css|js|woff2?|svg)$ {
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    location / {
        try_files $uri $uri/ /index.html;
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}

Siber Güvenlik Başlıkları

Tüm HTTP yanıtlarına katı güvenlik başlıkları eklenir:

  • X-Frame-Options "DENY"
  • X-Content-Type-Options "nosniff"
  • Strict-Transport-Security "max-age=31536000; includeSubDomains"
  • Content-Security-Policy ile yetkisiz script ve frame yüklemelerini engelleme.
