Modern Angular 21 Temel İlkeleri ve Çevre

Angular 21 ile birlikte kurumsal ölçekte eski pratikler (NgModule, Zone.js monkey patching, constructor-based DI) tamamen terk edilmiş; yerini ince taneli reaktivite, yüksek performanslı zoneless mimari ve modern build sistemlerine bırakmıştır.

Zoneless İlk

Zoneless Change Detection

zone.js tamamen devre dışı bırakılır. Değişiklik algılama DOM olaylarına veya monkey-patch'lere değil, yalnızca Signal bildirimlerine dayanır.

Signals First

Reaktif Sinyal Mimarisi

Bileşen durumu, hesaplanan türev değerler ve yan etkiler signal(), computed(), effect() ve yeni sinyal tabanlı I/O (input(), output()) ile yönetilir.

Standalone Only

%100 Standalone Bileşenler

Tüm Component, Directive ve Pipe'lar standalone'dur. NgModule kullanımı kesinlikle yasaktır ve kod tabanında yer almaz.

Modern Build

Application / esbuild Builder

Vite tabanlı geliştirme sunucusu ve esbuild destekli application derleyicisi ile saniyeler içinde HMR ve optimize üretim paketleri üretilir.

Angular 21 Zoneless Best Practice: `provideExperimentalZonelessChangeDetection()`

Uygulama genelinde zone.js kaldırılmalıdır. main.ts dosyasında import 'zone.js'; kesinlikle bulunmamalı, app.config.ts içerisinde provideExperimentalZonelessChangeDetection() sağlayıcısı tanımlanmalıdır.

A. Standart Uygulama Konfigürasyonu (app.config.ts)

Angular 21'de tüm küresel sağlayıcılar, HTTP istemcisi (interceptor'lar ile), rotalama ve zoneless desteği app.config.ts üzerinden yapılandırılır:

src/app/app.config.ts
TypeScript 
import { ApplicationConfig, provideExperimentalZonelessChangeDetection } from '@angular/core';
import { provideRouter, withComponentInputBinding, withViewTransitions, withInMemoryScrolling } from '@angular/router';
import { provideHttpClient, withInterceptors, withFetch } from '@angular/common/http';
import { routes } from './app.routes';
import { authInterceptor } from '@core/interceptors/auth.interceptor';
import { apiPrefixInterceptor } from '@core/interceptors/api-prefix.interceptor';
import { errorInterceptor } from '@core/interceptors/error.interceptor';

export const appConfig: ApplicationConfig = {
  providers: [
    // 1. Zone.js yerine modern Zoneless Change Detection
    provideExperimentalZonelessChangeDetection(),

    // 2. Gelişmiş Router konfigürasyonu (Route parametrelerini doğrudan component input()'larına bağlar)
    provideRouter(
      routes,
      withComponentInputBinding(),
      withViewTransitions(),
      withInMemoryScrolling({ scrollPositionRestoration: 'top' })
    ),

    // 3. fetch API tabanlı ve fonksiyonel interceptor zincirli HttpClient
    provideHttpClient(
      withFetch(),
      withInterceptors([
        apiPrefixInterceptor,
        authInterceptor,
        errorInterceptor
      ])
    )
  ]
};

B. Yeni Control Flow ve Sinyal Tabanlı Bileşen Standartları

Klasik *ngIf, *ngFor ve *ngSwitch direktifleri tamamen yasaklanmıştır. Angular 21'in yerleşik @if, @for (item of list; track item.id), @switch ve @let sözdizimi zorunludur:

src/app/features/users/user-list.component.ts
TypeScript 
import { Component, signal, computed, input, output, inject, ChangeDetectionStrategy } from '@angular/core';
import { CommonModule } from '@angular/common';
import { UserService } from '@core/services/user.service';
import { UserProfileResponse } from '@core/models/user.model';

@Component({
  selector: 'app-user-list',
  standalone: true,
  imports: [CommonModule],
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `
    <div class="user-container">
      @let totalCount = users().length;

      <div class="header-bar">
        <h2>Kullanıcılar ({{ totalCount }})</h2>
        <button (click)="refresh()" class="btn-refresh">Yenile</button>
      </div>

      @if (isLoading()) {
        <div class="skeleton-loader">Veriler yükleniyor...</div>
      } @else if (users().length === 0) {
        <p class="empty-state">Kayıtlı kullanıcı bulunamadı.</p>
      } @else {
        <ul class="user-cards">
          @for (user of users(); track user.publicId) {
            <li class="user-card" (click)="selectUser.emit(user)">
              <span class="user-name">{{ user.firstName }} {{ user.lastName }}</span>
              <span class="user-email">{{ user.email }}</span>
              <span class="badge" [class.badge-active]="user.status === 'ACTIVE'">
                {{ user.status }}
              </span>
            </li>
          }
        </ul>
      }
    </div>
  `
})
export class UserListComponent {
  // Sinyal tabanlı modern input ve output tanımları
  readonly roleFilter = input<string | null>(null);
  readonly selectUser = output<UserProfileResponse>();

  private readonly userService = inject(UserService);

  readonly users = this.userService.users;
  readonly isLoading = this.userService.isLoading;

  refresh(): void {
    this.userService.loadUsers();
  }
}

Kimlik Doğrulama, Kurumsal SSO & Spring Authorization Server Entegrasyonu

Kurumsal mimaride kimlik doğrulama, Spring Authorization Server'ın OAuth 2.1 ve OpenID Connect 1.0 protokolleri üzerinden PKCE (Proof Key for Code Exchange) mekanizması ile gerçekleştirilir. Client Secret SPA tarafında asla saklanmaz.

Güvenlik Uyarısı: SPA Token Güvenliği & Pre-Account Takeover Koruması

JWT Access Token'lar yalnızca In-Memory reaktif sinyalde (veya Web Worker içinde) tutulmalıdır. LocalStorage'a kalıcı Access Token yazılması XSS saldırılarına kapı açar. Refresh Token ise güvenli (HttpOnly, Secure, SameSite=Strict) çerezler ile arka uçta yönetilmelidir.

A. PKCE Yardımcı Fonksiyonları (Web Crypto API)

Harici bir kütüphaneye bağımlı kalmadan tarayıcının yerel crypto.subtle API'si ile kriptografik olarak rastgele code_verifier ve SHA-256 code_challenge üretilir:

src/app/core/auth/pkce.utils.ts
TypeScript 
export async function generateCodeVerifier(): Promise<string> {
  const array = new Uint8Array(64);
  window.crypto.getRandomValues(array);
  return base64UrlEncode(array);
}

export async function generateCodeChallenge(verifier: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(verifier);
  const digest = await window.crypto.subtle.digest('SHA-256', data);
  return base64UrlEncode(new Uint8Array(digest));
}

function base64UrlEncode(buffer: Uint8Array): string {
  let str = '';
  for (let i = 0; i < buffer.length; i++) {
    str += String.fromCharCode(buffer[i]);
  }
  return btoa(str)
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=+$/, '');
}

B. Signal Tabanlı Kimlik Doğrulama Servisi (AuthService)

Oturum açma durumu, kullanıcı profili ve roller Angular 21'in reaktif sinyalleri ile yönetilir:

src/app/core/auth/auth.service.ts
TypeScript 
import { Injectable, signal, computed, inject } from '@angular/core';
import { HttpClient, HttpHeaders, HttpParams } from '@angular/common/http';
import { Router } from '@angular/router';
import { environment } from '@env/environment';
import { generateCodeVerifier, generateCodeChallenge } from './pkce.utils';
import { UserProfileResponse } from '@core/models/user.model';
import { AuthTokenResponse } from '@core/models/auth.model';

const PKCE_VERIFIER_KEY = 'sso_pkce_verifier';

@Injectable({ providedIn: 'root' })
export class AuthService {
  private readonly http = inject(HttpClient);
  private readonly router = inject(Router);

  // In-Memory Reactive State
  private readonly _accessToken = signal<string | null>(null);
  private readonly _currentUser = signal<UserProfileResponse | null>(null);
  private readonly _isLoading = signal<boolean>(false);

  // Computed Selectors
  readonly accessToken = this._accessToken.asReadonly();
  readonly currentUser = this._currentUser.asReadonly();
  readonly isLoading = this._isLoading.asReadonly();
  readonly isAuthenticated = computed(() => !!this._accessToken() && !!this._currentUser());
  readonly userRoles = computed(() => this._currentUser()?.roles ?? []);

  // 1. SSO Giriş Akışını Başlat (Spring Authorization Server'a yönlendir)
  async redirectToSsoLogin(): Promise<void> {
    const verifier = await generateCodeVerifier();
    const challenge = await generateCodeChallenge(verifier);

    sessionStorage.setItem(PKCE_VERIFIER_KEY, verifier);

    const authUrl = new URL(`${environment.auth.issuer}/oauth2/authorize`);
    authUrl.searchParams.set('response_type', environment.auth.responseType);
    authUrl.searchParams.set('client_id', environment.auth.clientId);
    authUrl.searchParams.set('redirect_uri', environment.auth.redirectUri);
    authUrl.searchParams.set('scope', environment.auth.scope);
    authUrl.searchParams.set('code_challenge', challenge);
    authUrl.searchParams.set('code_challenge_method', 'S256');

    window.location.href = authUrl.toString();
  }

  // 2. OAuth2 Authorization Code Callback İşleme
  async handleAuthCallback(code: string): Promise<void> {
    const verifier = sessionStorage.getItem(PKCE_VERIFIER_KEY);
    if (!verifier) throw new Error('PKCE Code Verifier bulunamadı.');

    this._isLoading.set(true);

    const body = new HttpParams()
      .set('grant_type', 'authorization_code')
      .set('client_id', environment.auth.clientId)
      .set('redirect_uri', environment.auth.redirectUri)
      .set('code', code)
      .set('code_verifier', verifier);

    const headers = new HttpHeaders({ 'Content-Type': 'application/x-www-form-urlencoded' });

    try {
      const tokenRes = await this.http.post<AuthTokenResponse>(
        `${environment.auth.issuer}/oauth2/token`,
        body.toString(),
        { headers }
      ).toPromise();

      if (tokenRes?.access_token) {
        sessionStorage.removeItem(PKCE_VERIFIER_KEY);
        this._accessToken.set(tokenRes.access_token);
        await this.fetchCurrentUserProfile();
        this.router.navigate(['/dashboard']);
      }
    } finally {
      this._isLoading.set(false);
    }
  }

  // 3. Kullanıcı Profilini Getir (/api/v1/users/me)
  async fetchCurrentUserProfile(): Promise<void> {
    const res = await this.http.get<{ data: UserProfileResponse }>('/api/v1/users/me').toPromise();
    if (res?.data) {
      this._currentUser.set(res.data);
    }
  }

  // 4. Güvenli Çıkış (Logout)
  logout(): void {
    this._accessToken.set(null);
    this._currentUser.set(null);
    window.location.href = environment.auth.postLogoutRedirectUri;
  }
}

C. Modern Fonksiyonel Interceptor'lar

Angular 21'de HttpInterceptorFn kullanılır. Access token ekleme ve Spring Boot RFC 7807 ProblemDetail hata yakalama mekanizması:

src/app/core/interceptors/auth.interceptor.ts
TypeScript 
import { HttpInterceptorFn } from '@angular/common/http';
import { inject } from '@angular/core';
import { AuthService } from '@core/auth/auth.service';

export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const authService = inject(AuthService);
  const token = authService.accessToken();

  // OAuth2 token uç noktalarına istek atılırken header eklenmez
  if (req.url.includes('/oauth2/') || !token) {
    return next(req);
  }

  const clonedReq = req.clone({
    setHeaders: {
      Authorization: `Bearer ${token}`
    }
  });

  return next(clonedReq);
};
src/app/core/interceptors/error.interceptor.ts (RFC 7807 Handler)
TypeScript 
import { HttpInterceptorFn, HttpErrorResponse } from '@angular/common/http';
import { inject } from '@angular/core';
import { Router } from '@angular/router';
import { catchError, throwError } from 'rxjs';
import { ToastService } from '@core/services/toast.service';
import { AuthService } from '@core/auth/auth.service';
import { ProblemDetail } from '@core/models/problem-detail.model';

export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  const toast = inject(ToastService);
  const router = inject(Router);
  const auth = inject(AuthService);

  return next(req).pipe(
    catchError((error: HttpErrorResponse) => {
      // 1. Spring Boot RFC 7807 ProblemDetail gövdesini parse et
      const problem: ProblemDetail | null = error.error ?? null;

      if (error.status === 401) {
        toast.error('Oturum süreniz doldu, lütfen tekrar giriş yapın.');
        auth.logout();
      } else if (error.status === 403) {
        toast.error('Bu işlemi gerçekleştirmek için yetkiniz bulunmamaktadır.');
      } else if (error.status === 400 && problem?.invalidParams) {
        // Jakarta Validation hata listesi
        const details = problem.invalidParams.map(p => `${p.field}: ${p.reason}`).join(', ');
        toast.warning(`Form doğrulama hatası: ${details}`);
      } else {
        toast.error(problem?.detail || error.message || 'Beklenmedik bir hata oluştu.');
      }

      return throwError(() => error);
    })
  );
};

import { Injectable, signal, computed, inject } from '@angular/core';
import { HttpClient, HttpParams } from '@angular/common/http';
import { rxResource } from '@angular/core/rxjs-interop';
import { UserProfileResponse, PageResponse } from '@core/models/user.model';

@Injectable({ providedIn: 'root' })
export class UserService {
  private readonly http = inject(HttpClient);

  // Sinyal tabanlı filtre ve sayfalama parametreleri
  readonly searchQuery = signal<string>('');
  readonly page = signal<number>(0);
  readonly pageSize = signal<number>(10);

  // rxResource: Parametre sinyalleri değiştikçe otomatik olarak HTTP isteği tetikler
  readonly userResource = rxResource({
    request: () => ({
      query: this.searchQuery(),
      page: this.page(),
      size: this.pageSize()
    }),
    loader: ({ request }) => {
      const params = new HttpParams()
        .set('query', request.query)
        .set('page', request.page.toString())
        .set('size', request.size.toString());

      return this.http.get<PageResponse<UserProfileResponse>>('/api/v1/users', { params });
    }
  });

  // Kolay erişim için computed sinyaller
  readonly users = computed(() => this.userResource.value()?.content ?? []);
  readonly totalElements = computed(() => this.userResource.value()?.totalElements ?? 0);
  readonly isLoading = this.userResource.isLoading;

  setSearch(query: string): void {
    this.page.set(0); // Yeni aramada ilk sayfaya dön
    this.searchQuery.set(query);
  }

  setPage(newPage: number): void {
    this.page.set(newPage);
  }

  reload(): void {
    this.userResource.reload();
  }
}

import { Injectable, signal } from '@angular/core';

export interface ToastMessage {
  id: string;
  type: 'success' | 'error' | 'warning' | 'info';
  message: string;
  duration?: number;
}

@Injectable({ providedIn: 'root' })
export class ToastService {
  private readonly _toasts = signal<ToastMessage[]>([]);
  readonly toasts = this._toasts.asReadonly();

  show(type: ToastMessage['type'], message: string, duration = 4000): void {
    const id = window.crypto.randomUUID();
    const toast: ToastMessage = { id, type, message, duration };

    this._toasts.update(prev => [...prev, toast]);

    if (duration > 0) {
      setTimeout(() => this.remove(id), duration);
    }
  }

  success(msg: string): void { this.show('success', msg); }
  error(msg: string): void { this.show('error', msg, 6000); }
  warning(msg: string): void { this.show('warning', msg, 5000); }
  info(msg: string): void { this.show('info', msg); }

  remove(id: string): void {
    this._toasts.update(prev => prev.filter(t => t.id !== id));
  }
}

import { Injectable, signal, effect } from '@angular/core';

export type ThemeMode = 'dark' | 'light';

@Injectable({ providedIn: 'root' })
export class ThemeService {
  private readonly THEME_KEY = 'app_theme_mode';
  readonly currentTheme = signal<ThemeMode>(this.getInitialTheme());

  constructor() {
    // Sinyal değiştikçe HTML data-theme özniteliğini ve LocalStorage'ı senkronize et
    effect(() => {
      const theme = this.currentTheme();
      document.documentElement.setAttribute('data-theme', theme);
      localStorage.setItem(this.THEME_KEY, theme);
    });
  }

  toggleTheme(): void {
    this.currentTheme.update(prev => prev === 'dark' ? 'light' : 'dark');
  }

  private getInitialTheme(): ThemeMode {
    const saved = localStorage.getItem(this.THEME_KEY) as ThemeMode | null;
    if (saved) return saved;
    return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
  }
}

  private readonly http = inject(HttpClient);
  private readonly router = inject(Router);
  private readonly toast = inject(ToastService);

  readonly form = this.fb.nonNullable.group({
    email: ['', [Validators.required, Validators.email]],
    firstName: ['', [Validators.required, Validators.minLength(2), Validators.maxLength(50)]],

server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # Gzip Sıkıştırma
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_proxied expired no-cache no-store private auth;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/x-javascript application/xml application/json image/svg+xml;
    gzip_disable "MSIE [1-6]\.";

    # Kurumsal Siber Güvenlik Başlıkları
    add_header X-Frame-Options "DENY" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; font-src 'self' data:; connect-src 'self' https://api.enterprise.com https://auth.enterprise.com;" always;

    # Statik Varlıklar için Uzun Süreli Önbellek (Cache-Control: 1 Yıl)
    location ~* \.(?:css|js|woff2?|svg|gif|png|jpe?g|ico)$ {
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
        access_log off;
    }

    # SPA Fallback Rotalama: Tanımlanmayan yolları index.html'e yönlendir
    location / {
        try_files $uri $uri/ /index.html;
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Sağlık Kontrolü (Health Check Endpoint)
    location /healthz {
        access_log off;
        return 200 "healthy\n";
